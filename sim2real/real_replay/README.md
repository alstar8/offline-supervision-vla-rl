# real_replay

Запуск траекторий, сгенерированных в ManiSkill, на реальном RC5 + AeroHand.

`replay_npz_real.py` — адаптация `rc5_aerohand_teleop/replay_jsonl_real.py` под формат NPZ.
Путь управления железом (jog P-контроллер, E-stop, workspace-клампы) намеренно оставлен
идентичным проверенному оригиналу; отличается только источник траектории.

## Использование

```bash
# Dry-run: только статистика, без железа. ВСЕГДА запускать первым.
python3 replay_npz_real.py ../runs/manual/pick_up_green_cube_ext_20260907_095442 --dry-run

# На реальном роботе
python3 replay_npz_real.py ../runs/manual/pick_up_green_cube_ext_20260907_095442

# Медленнее
python3 replay_npz_real.py <run_dir> --speed 0.3
```

Принимает как директорию прогона (найдёт `rl4vla_raw_episode*.npz`, предпочитая `_success`),
так и путь к самому `.npz`.

Ctrl+C в любой момент → E-stop (робот в hold, кисть открывается).

## Отличия формата от JSONL

| | JSONL (teleop) | NPZ (ManiSkill) |
|---|---|---|
| Поза | `abs_pose` — абсолютная | только дельты EE |
| Время | `t` в записи | шаги × control_freq (20 Гц) |
| Кисть | 7 углов на каждый кадр | один тернарный канал: hold / open / close |
| Кадр | фрейм реального робота | фрейм базы симулятора |

Соответственно:

- **Абсолютные позы восстанавливаются интегрированием дельт** от позы робота на старте
  (или от `--start-pose`). В отличие от JSONL-реплея, здесь есть накопление ошибки.
- **Кисть**: при запуске по папке траектории поза пальцев читается из `runtime_config.yaml`
  этой папки (при запуске по прямому пути к `.npz` — из встроенной копии конфига).
  Подробнее ниже.
- **Ремапа фрейма нет.** Дельты применяются в том виде, в каком записаны. Dry-run печатает
  суммарное смещение (`Net XYZ delta`) в исходном фрейме эпизода — сверьте с реальной
  ячейкой до запуска на железе.

## Положения пальцев AeroHand

`AeroHand.set_joint_positions()` принимает **углы суставов в градусах** и сам внутри
прогоняет модель сухожилий (`JointsToActuationsModel`), пересчитывая их в 7 актуаторов.
Поэтому в скрипте ничего пересчитывать не нужно и нельзя — иначе конверсия произойдёт
дважды.

Короткая форма из 7 значений разворачивается SDK в 16 суставов так:

```
[0] thumb_cmc_abd   [1] thumb_cmc_flex   [2] thumb_mcp = thumb_ip
[3] index x3        [4] middle x3        [5] ring x3        [6] pinky x3
```

| состояние | константа | значение | пределы |
|---|---|---|---|
| HOLD (и OPEN) | `HAND_HOLD` | `[70, 3.5, 14, 37.4, 29.4, 30.2, 29.4]` | 100, 55, 90, 90, 90, 90, 90 |
| CLOSE | `HAND_CLOSE` | `[100, 55, 30, 60, 60, 60, 60]` | — |

`HAND_HOLD` — профиль `side` из `robot_init_qpos` (та поза, что проверялась на рендере
кисти), углы переведены из радиан в градусы. Отведение большого пальца снижено со 100°
(предел сустава, как в профиле) до **70°** — на реальной кисти при 100° он выпирает
слишком сильно. У этого профиля все три фаланги
каждого пальца имеют одинаковый угол, поэтому он точно ложится в форму из 7 значений.

Профиль `top` в 7 значений **не сводится** (mcp/pip/dip различаются) — для него нужна
форма из 16, `set_joint_positions` её тоже принимает:

```
[44.94, 8.58, 11.22, 20.05, 20.26, 25.15, 25.06, 15.25,
 30.14, 20.05, 15.25, 30.15, 20.05, 1.81, 40.17, 20.06]
```

При старте скрипт проверяет, что `HAND_HOLD` не выходит за суставные пределы.

## Важное ограничение: дельты — это цели, а не пройденный путь

Control mode эпизодов — `arm_pd_ee_target_delta_pose_align2_gripper_pd_joint_pos`,
то есть `use_target=True`: каждая дельта прибавляется к *целевой* позе замкнутого контура,
а не к достигнутой. Планировщик в симуляции — тоже замкнутый P-контроллер: пока рука
отстаёт, он продолжает выдавать дельты. В результате **сумма дельт заметно больше
фактического перемещения**.

Замер на `pick_up_green_cube_ext_20260907_095442`:

| Стадия | Команда (сумма дельт) | Факт в симуляции | Превышение |
|---|---|---|---|
| Спуск | 23.3 см | 21.2 см | ×1.1 |
| Подъём | 25.2 см | 9.5 см | **×2.6** |

Скрипт считает это расхождение в dry-run и печатает предупреждение. Открытый реплей
дельт проедет дальше, чем ездила симуляция — особенно на подъёме.

Аккуратный способ это закрыть — экспортировать из симуляции абсолютные позы TCP по шагам
и реплеить их (как `abs_pose` в JSONL-варианте). Сейчас в NPZ их нет.
